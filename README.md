# Intraepithelial IL1A signaling promotes human esophageal inflammation while safeguarding epithelial basal cell identity and barrier function

Code repository accompanying:

**Evelien Eenjes, Maeve L. Troost, Li Lei, Alicia Köck, David Grommisch, Marin T. Mondria, Kotryna Truskaite, Fredrik Klevebro, Magnus Nilsson, and Maria Genander**

This repository contains the R code used for the single-cell RNA-seq and bulk RNA-seq processing, analysis, and visualization presented in the manuscript.

## Overview

The computational analyses in this repository include:

- processing and quality control of the human esophageal single-cell RNA-seq dataset;
- doublet detection and removal;
- Harmony-based integration across donors;
- dimensionality reduction and epithelial cell-state visualization;
- cell-cycle scoring;
- gene-expression and gene-signature visualization;
- cell-cell communication analysis using MultiNicheNet/NicheNet;
- bulk RNA-seq count-matrix processing;
- paired differential-expression analysis using DESeq2;
- PCA and library-size quality control;
- heatmaps and volcano plots;
- gene-set enrichment analysis;
- projection of bulk RNA-seq-derived NGFR-positive and NGFR-negative transcriptional signatures onto single-cell UMAP embeddings.

## Single-cell RNA-seq analysis

### `01_EoE_scRNA_processing.R`

Main single-cell RNA-seq processing workflow.

The script includes:

1. raw matrix import;
2. addition of clinical and reference metadata;
3. downsampling;
4. quality-control filtering;
5. cell-type regrouping;
6. doublet detection with DoubletFinder;
7. normalization and variable-feature selection;
8. PCA;
9. Harmony correction using patient identity;
10. UMAP and t-SNE;
11. cell-cycle scoring;
12. final clustering and cell-type regrouping;
13. generation of an epithelial-only Seurat object.

The final clustering workflow uses 25 Harmony dimensions and a clustering resolution of 0.7.

### `02_Figure1.R`

Code used for the single-cell RNA-seq panels associated with **Figure 1**, including:

- epithelial UMAP;
- epithelial differentiation-marker heatmap.

Microscopy-based panels are not generated by this R script.

### `03_FigureS1.R`

Code used for the single-cell RNA-seq panels associated with **Figure S1**, including:

- UMAP of major cell populations;
- Nebulosa density plots of lineage markers;
- immune-cell marker dot plot;
- epithelial marker expression;
- cell-cycle visualization;
- cell-cycle phase distribution;
- epithelial gene-density overlap plots.

### `04_Figure2.R`

Code used for the computational panel in **Figure 2** in which bulk RNA-seq-derived NGFR-positive and NGFR-negative signatures are projected onto the epithelial single-cell RNA-seq UMAP.

The signatures consist of the **top 50 differentially expressed genes** from the tissue-derived NGFR-positive versus NGFR-negative bulk RNA-seq comparison.

### `05_Figure3.R`

Code used for the computational panel in **Figure 3** in which organoid-derived NGFR-positive and NGFR-negative signatures are projected onto the epithelial single-cell RNA-seq UMAP.

The signatures consist of the **top 50 differentially expressed genes** from the P1 control organoid NGFR-positive versus NGFR-negative bulk RNA-seq comparison.

### `06_Figure4.R`

Code used for computational panels associated with **Figure 4**, including:

- epithelial UMAP;
- MultiNicheNet cell-cell communication analysis directed toward basal cells;
- top ligand-receptor interaction visualization;
- IL1A expression analysis.

For the MultiNicheNet visualization, interactions were filtered to those targeting basal cells and the top 20 incoming ligand-receptor interactions were displayed.

Microscopy-based panels are not generated by this R script.

### `07_FigureS4.R`

Code used for computational panels associated with **Figure S4**, including:

- healthy versus EoE epithelial UMAPs;
- epithelial cell-state proportions;
- cell-cycle phase distributions;
- IL13, IL33, IL36B, IL1A, and IL1B expression;
- donor-level IL1A expression in apical cells;
- IL1-family receptor expression across epithelial cell states.

## Bulk RNA-seq analysis

The bulk RNA-seq scripts are organized according to the order of the analysis workflow.

### `08_BulkRNA_01_Preprocessing.R`

Prepares the raw bulk RNA-seq count matrix.

Main steps:

1. load the raw count matrix;
2. filter low-expression genes;
3. reorganize sample identifiers;
4. apply sample exclusions used in the original analysis;
5. generate pairwise count matrices for downstream analyses.

The filtering used in the final workflow retains genes with:

- total counts > 100 across all samples; and
- non-zero expression in at least 50% of samples.

The following pairwise comparisons are generated:

1. P0 NGFR-positive versus NGFR-negative;
2. P1 control NGFR-positive versus NGFR-negative;
3. control NGFR-positive P1 versus P0;
4. control NGFR-negative P1 versus P0;
5. P1 IL1A versus control, with NGFR-positive and NGFR-negative populations combined;
6. P1 NGFR-positive IL1A versus control;
7. P1 NGFR-negative IL1A versus control.

### `09_BulkRNA_02_PCA_QC.R`

Performs PCA and library-size quality control.

For PCA, raw counts are transformed as:

```r
log2(counts + 1)
```

Genes with zero variance are removed before PCA, and PCA is performed using:

```r
prcomp(t(log_counts), scale. = TRUE)
```

The script also contains a reusable function for comparison of raw and DESeq2-normalized library sizes.

### `10_BulkRNA_03_Paired_DESeq2.R`

Performs paired differential-expression analysis using DESeq2.

The final analysis uses donor identity as a blocking factor:

```r
design = ~ patient + condition
```

For each comparison, the script exports:

- complete DESeq2 results;
- normalized counts;
- rlog-transformed counts.

Differential-expression results used for the main downstream visualizations are primarily evaluated using:

```text
|log2 fold change| > 0.585
adjusted P value < 0.05
```

### `11_BulkRNA_04_Heatmap_Volcano.R`

Generates:

- marker-expression heatmaps;
- volcano plots for the major pairwise bulk RNA-seq comparisons.

Expression heatmaps use row-wise z-score scaling and a blue-white-red color scale.

### `12_BulkRNA_05_GSEA_GO.R`

Performs gene-set enrichment analyses.

The analysis uses the gene-set file downloaded from MsigDB:

```text
v2024.1.Hs.symbols.gmt
```

The script includes:

- ranked GSEA;
- selected pathway enrichment plots;
- over-representation analysis.

### `13_BulkRNA_06_Targeted_Analysis.R`

Contains targeted downstream bulk RNA-seq analyses, including:

- IL1-family expression heatmaps;
- extraction of the top 50 NGFR-positive and NGFR-negative gene signatures used for the single-cell projections in Figures 2 and 3.

The single-cell `AddModuleScore` visualization of these signatures is kept in the corresponding figure-specific scripts rather than duplicated in this file.

## Running the analysis

The scripts were developed and executed in R on Windows.

Several scripts contain file paths reflecting the directory structure used during the original analysis. Before running the scripts on another computer, these paths may need to be adjusted to match the local location of the input data.

A recommended execution order is:

```text
01_EoE_scRNA_processing.R

02_Figure1.R
03_FigureS1.R
04_Figure2.R
05_Figure3.R
06_Figure4.R
07_FigureS4.R

08_BulkRNA_01_Preprocessing.R
09_BulkRNA_02_PCA_QC.R
10_BulkRNA_03_Paired_DESeq2.R
11_BulkRNA_04_Heatmap_Volcano.R
12_BulkRNA_05_GSEA_GO.R
13_BulkRNA_06_Targeted_Analysis.R
```

Figure scripts assume that the processed objects or analysis outputs generated by the corresponding upstream scripts are available.

## Reproducibility notes

- The scripts were organized from the analysis code used for the manuscript and retain the original analysis parameters.
- Some scripts use absolute local paths from the original analysis environment; these should be adjusted before execution on another system.
- Large intermediate Seurat objects, count matrices, and other processed datasets are not intended to be stored directly in this Git repository.
- Microscopy panels and other image-based experimental figures are outside the scope of these R scripts.
- Bulk RNA-seq comparisons involving samples from the same donor use paired DESeq2 models with donor identity included in the design.
- Bulk-derived NGFR-positive and NGFR-negative signatures used in the single-cell projections are based on the top 50 differentially expressed genes from the corresponding bulk RNA-seq comparisons.
